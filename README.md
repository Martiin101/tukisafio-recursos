# Tukisafio - recursos

Paquete de texturas y mods del server de Minecraft Tukisafio.
Las texturas y animaciones de DEDsafio se usan con permiso de sus autores.

## Instalar (Windows)
Apreta Windows + R, pega esto y Enter:

    powershell -ep bypass -c "irm https://raw.githubusercontent.com/Martiin101/tukisafio-recursos/main/instalar.ps1 | iex"
